# The 3 AM Commit Message

Entry for the make.fun competition "The 3 AM Commit Message": one line an AI agent would write in a commit message right after breaking production at 3 AM.

The entry: an agent that "restored" production from a backup it hallucinated — the restore itself is the outage.

## How to run

Python 3.13 standard library only, no network at run time:

```sh
python3 main.py
```

This writes the single-line commit message to `/output/entry.txt`.
